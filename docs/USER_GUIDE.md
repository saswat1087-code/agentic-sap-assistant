## 🚀 Getting Started

### Accessing the Assistant

The Agentic SAP Assistant is available through:

- **Web Browser**: Navigate to `http://your-server:8501`
- **Mobile Device**: Optimized for tablet and smartphone viewing
- **Docker Desktop**: If running locally, access via `http://localhost:8501`

### First Time Login

1. No login required (if deployed internally)
2. Ensure you have access to the network where the assistant is hosted
3. Clear browser cache if you experience display issues
